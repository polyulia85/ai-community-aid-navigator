# V8 adaptive intake preview

This is a **local deterministic prototype**, not an AI agent or real Supervisor.
Unlike v7, it asks for a cause of hardship and skips some questions when facts
are explicitly present in the initial story. It collects a small set of fields
and shows Summary only when all required test fields are populated.
This is NOT a verified sufficiency assessment for any real program.

Summary is editable. Confirming does not generate a personalized plan.
The Action Plan button is clearly labeled preview/status and the separate
synthetic bridge is not fed conversation answers.

Next integration: real Supervisor/Agent 1/2 contracts, dynamic follow-ups
based on verified KB, validation, consent and user-confirmed case facts.
